# 参考环境配置（本部署，供对比）

## 硬件
- 4× DGX Spark (NVIDIA GB10, 121GB 统一内存, 每台双 HCA CX7 200G)
- 网络: MikroTik CRS812 交换机, 200G RoCE (单线), MTU 9000
- 系统: Ubuntu 24.04 / kernel 6.17.0-1029 / driver 580.173.02

## 部署栈
- 镜像: ghcr.io/anemll/dspark-vllm-gx10:0.1.1-nccl2312
- NCCL: 2.31.2 overlay (LD_PRELOAD=libnccl.so.2)
- TP=4 四节点 (nnodes=4)

## 推理配置
- model: deepseek-v4-flash-0731 (NVFP4, 156GB/48 shards)
- max_model_len: 1048576 (1M)
- max_num_seqs: 16
- max_num_batched_tokens: 8240
- gpu_memory_utilization: 0.82
- kv_cache_dtype: nvfp4_ds_mla
- MTP 投机: dspark, num_speculative_tokens=5
- enable_flashinfer_autotune: True
- moe_backend: flashinfer_b12x
- enable_chunked_prefill: True

## 测试文本
- fox: "The quick brown fox jumps over the lazy dog. " × 60 (P512) 或 × 30 (P256)
- Agent 场景: Math/JSON/Code/Communication/Narrative (见脚本内 prompt)

## 关键教训
1. decode-only 口径（自首 token 计时）是唯一可比口径
2. 充分预热（编译收敛）后再测试
3. 多轮取中位（单流波动 40-124）
