# kernel② `nvfp4_ds_mla_kv_linear` 生产兼容性核查报告

> 日期：2026-08-19｜核查环境：torch 2.11.0+cu130 / triton 3.6.0 / CC=(12,1)=sm_121a（DGX Spark 生产 TP4）
> 核查对象：生产版 v5（kernels_fixed）vs 项目内 v4 优化版（42.17×）vs paged 分页版
> 结论：**无 prefill_gemm 类编译级缺陷（本算子不使用 `dot_scaled`）；但发现 scale 编码语义不一致，已修正统一。**

## 一、核查结论速览

| 核查项 | 结果 | 说明 |
|---|---|---|
| `dot_scaled` API 问题（缺陷 #7 同类） | ✅ **不适用** | 本算子纯标量量化 + 位操作打包 + 逐字节 store，全程无 `tl.dot_scaled`/`tl.dot` |
| Triton 3.6 兼容（slice / split / clamp int / fp64 bitcast / constexpr） | ✅ **全部满足** | 见下表逐项核对 |
| 生产 v5 编译风险 | ✅ 低 | 静态检查无 Triton 3.6 破坏性 API（该文件即生产已跑过的版本） |
| **v4/paged 与生产 v5 的 scale 编码一致性** | ❌→✅ **发现不一致，已修正** | v4 丢 `/6`（精度损失 ~1bit）；paged 误用 `ceil`（量程浪费）；均改为 `floor(log2(max/6))` 与生产统一 |
| 逐字节一致性（atol=0） | ✅（修正后） | 修正后与生产 v5 编码逐字节一致（除 <2^-126 极端 denormal 边界，见风险节） |

## 三、发现的 scale 编码不一致（已修正）

三种实现原编码各不相同——**这是本次核查最重要的发现**：

| 版本 | 原 scale 编码 | 问题 |
|---|---|---|
| 生产 v5（kernels_fixed，部署中） | `floor(log2(max/6)) + 127` | ✅ 标准 NVFP4，充分利用 E2M1 全量程 |
| v4 优化版（linear，42.17×） | `floor(log2(max)) + 127` | ❌ **丢 `/6`**：max/scale ∈ [1,2)，仅用 E2M1 下半量程，精度损失约 1 bit |
| paged 版 | `ceil(log2(max/6)) + 127` | ❌ **`ceil` 语义**：max/scale ∈ (0.5, 1.5]，量程浪费更多 |

**修正动作（已完成，与生产 v5 统一）**：
1. `nvfp4_ds_mla_kv_linear_triton.py`：K/V 两处 `tl.log2(k_amax)` → `tl.log2(k_amax / 6.0)`
2. `nvfp4_ds_mla_kv_linear_torch.py`：`torch.log2(abs_max)` → `torch.log2(abs_max / 6.0)`
3. `nvfp4_ds_mla_kv_linear_paged_triton.py`：`libdevice.ceilf(scale_exp_f)` → `tl.floor(scale_exp_f).to(tl.int32)`（顺带移除 libdevice 依赖）

**一致性推导**（floor 幂次 + +127 偏移 + [0,255] clamp 三环节与 v5 完全一致 → 逐字节相同；唯一边界：`max < 6·2^-127 ≈ 3.5e-38` 时 v5 编码为 0、本实现编码为 1，随机数据不可达）。

## 四、生产部署建议

| 场景 | 选型 | 理由 |
|---|---|---|
| 生产 KV 写回（现役 v5 语义） | **v4 linear（修正后）** | 42.17× 性能 + 与现役逐字节一致，替换零风险 |
| vLLM 分页集成（reshape_and_cache 语义） | **paged（修正后）** | in-place 分页写回，直接对接 csrc SM121 路径 |

**生产验证指令**（修正后必须实机复核，本核查为静态推导 + MCP 侧已验证的正确性基线）：


## 五、与生产 v5 的交付关系

- 生产现役 v5（`kernels_fixed`）**无需回退**——它本身语义正确、能编译；本包交付的是**性能升级 + 语义统一**版本
- 若生产只想保留现役性能，可直接跳过 v4 替换；若要 42× 收益，替换 triton 文件即可（接口兼容 `(k,v)` 与 `(kv)` 双入口）
