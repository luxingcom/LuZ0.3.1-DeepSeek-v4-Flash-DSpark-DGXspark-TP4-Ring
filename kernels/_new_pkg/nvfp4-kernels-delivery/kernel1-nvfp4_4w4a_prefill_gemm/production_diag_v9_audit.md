## 二、v9 审查结论（job 39f30714，8 轮全过但不可用）

### 2.1 最终代码关键行（第 208 行）

```python
acc += tl.dot(a_quant_fp4, w_full, allow_tf32=False)   # ← fp32 GEMM，非 FP4 MMA
```

- A 量化：32 分组归一化 → 最近 E2M1（fp32 值域）→ **乘回 scale 还原为 fp32**（第 140 行 `a_q = best * a_sign * scale_col`）
- W：解包 nibble → fp32 值 → **乘回 scale**（第 206 行）→ `tl.dot`（fp32×fp32）
- 即"伪 4W4A"：量化精度语义对，但 GEMM 跑 **fp32 tensor core**

### 2.2 不可用理由（3 条）

1. **性能目标不可能达成**：GB10 FP4 MMA 峰值 500 TFLOPS，fp32 仅 ~40–80 TFLOPS → 无法达到 ≥400 TFLOPS 验收线
2. **接口被改坏**：wrapper 变为 `(A, W_packed, A_scale, W_scale, bias)` **5 参数**（新增 A_scale 输入，第 222 行），与转换器输出（4 参约定）、生产测试脚手架（`triton_impl(A, W_quant, W_scale, bias)`）全部不兼容
3. **未触碰缺陷 7 的实质**：没写 `dot_scaled`，自然"不报错"——但那是回避，不是修复

### 2.3 迭代数据

- verify：8/8 `passed=True`（total_tests=0——**数值比对本身没跑**，只有 harness 脚手架自检）
- performance：`speedup: null`（benchmark 全程被 harness CPU/GPU 索引问题挡）
- 结论：**v9 应弃用，不得合入生产**。

## 四、缺陷 7 的正解：v10（对齐 Triton 3.6 实测签名）

### 4.1 Triton 3.6 `dot_scaled` 实测签名（诊断 4.1 确认）

```python
tl.dot_scaled(lhs, lhs_scale, lhs_format,        # lhs_format 必填位置参数
              rhs, rhs_scale, rhs_format,
              acc=None, fast_math=False,
              lhs_k_pack=True, rhs_k_pack=True,  # SM120/121 需 rhs_k_pack=True
              out_dtype=tl.float32)
```

硬约束：
- `lhs_format`/`rhs_format` = `'e2m1'`，**位置参数**（无 `lhs_type`/`rhs_type` 关键字）
- e8m0 scale **group = 32 沿 K**（硬性）：`lhs_scale [M, K//32]`，`rhs_scale [N, K//32]`（**不转置**）
- lhs 形状 `[M, K]`、rhs 形状 `[N, K]`（W 转置后），e2m1 数据 **2:1 打包**（每字节 2 元素，K 方向）

### 4.2 v10 数据流（一次 dot_scaled 整块调用，无逐 g 循环）

```
A fp32 [BM, BK]
  ├─ reshape [BM, BK//32, 32] → max → E8M0(u8) → fp32  → lhs_scale [BM, BK//32]
  └─ 归一化 → 最近 E2M1 → nibble → 打包 → lhs [BM, BK//2] uint8
W_packed [BK, BN//2]
  ├─ nibble 解包 → interleave [BK, BN] → trans [BN, BK]
  ├─ 按 [n, k] 重打包（K 方向 2:1）→ rhs [BN, BK//2] uint8
  └─ W_scale [BK//32, BN//128] → load 展开 [BN, BK//32]（每 128 N 行共享一行 scale）→ fp32
acc += tl.dot_scaled(lhs, lhs_scale, 'e2m1', rhs, rhs_scale, 'e2m1',
                     acc=acc, rhs_k_pack=True, out_dtype=tl.float32)
```

### 4.3 配套连带改动（v10 落地必须同步）

| 文件 | 改动 |
