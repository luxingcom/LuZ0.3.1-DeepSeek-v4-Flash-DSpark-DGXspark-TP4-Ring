## 3. 算子规格（584-byte sparse-MLA envelope，对齐 vLLM PR #46329）

```
输入: k_state, v_state [T, 512] fp32（MLA 每 token 的 K/V 隐状态，单 KV head）
输出: uint8 [T, 584]，线性布局（无 4-token swizzle，SM121 FlashInfer FA2 reader 兼容）:
  [0:256]   K NVFP4 打包（e2m1 2 值/字节，低半字节优先）
  [256:512] V NVFP4 打包
  [512:544] K E8M0 block scale（512/16=32 个）
  [544:576] V E8M0 block scale
  [576:584] 零填充
```

- 量化：per-16 block max → `floor(log2(max/6))+127` 编码 E8M0 → 阈值量化 e2m1（0/0.5/1/1.5/2/3/4/6）→ 打包
- 内核实现：每 token 一个 program，树归约求块 max（16 元素全展开），标量位运算量化打包，无 slice 索引
- 价值：NVFP4 KV 使上下文 KV 带宽降 2–4×（MLA KV 本就≈GQA 的 2%），长上下文（1M）收益显著；线性布局规避 SM100 swizzle 的 FlashInfer 兼容问题
