### F vs D（跨代）
- c1 单流：F 与 D 几乎无差（38.5-41.7 vs 39.0-40.7 t/s）
- **并发是决定性差异**：D seqs=1 无法并行（c3/c5 agg 恒定 ~34-37 t/s，TTFT 排队 4-15s）；F seqs=6 c3 60-68 / c5 78-91 t/s（**+70%~+160%**）

### Greedy vs Probabilistic 机制说明（Tessa）
- **greedy**：draft 为 argmax 点质量 q(x*)=1，接受率=min(1,p(x*))=p(x*)，输出严格服从 target 分布（无偏）；同题数学 probe 接受率 79.2%（更高，符合理论）
- **probabilistic**：draft 采样分布 q(x)，接受率=min(1,p(x)/q(x)) 无偏，但低置信位置与 target 分歧导致接受率略低（74.4%）
- **关键洞察**：接受率强依赖 workload——此前团队参考值（~40% vs ~24%）是 **thinking 负载**，本次矩阵窗口（短输出）两者接近持平（34.1% vs 35.9%）；**F 的稳态性能优势不在投机采样，而在镜像补丁/缓存/生产可用性**（12 补丁固化、jit-cache、无 11 overlay 挂载）
