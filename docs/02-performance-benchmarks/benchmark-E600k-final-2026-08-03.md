## 🔧 变更摘要（Rex）

### head 管理网 SSH 修复
- **根因**：head 无线接口 wlP9s9 DOWN（NO-CARRIER，无线"珉珉家"未激活），原 <NODE_IP> 随无线漂移消失；head 实际经有线 enP7s7 拿 DHCP .52
- **修复**：有线 enP7s7 补 `<NODE_IP>/24` secondary IP（运行时 ip addr + 持久化 nmcli/netplan），直连验证通过（ssh <NODE_IP> exit=0 / ping 0% loss / nc 22 succeeded）

### E-600k/0.80 参数（diff 仅 2 处，备份 .bak.600k）
- `--max-model-len 800000` → **600000**；`--gpu-memory-utilization 0.9` → **0.80**
- 其余不变（seqs 6 / capture 24 / nvfp4 / wrapper / patch / api-key / 缓存卷 / 25000 FW 未破坏）

## 📊 内存监控对照（用户要求）

| 参数 | Head MemAvailable | Worker MemAvailable | GPU KV cache |
|---|---|---|---|
| 800k / 0.9 | 2.27 GB | 1.37 GB | 5,414,942 tokens |
| **600k / 0.80** | **15.96 GB** | **16.14 GB** | **2,564,354 tokens** |
| 变化 | **+602%** | **+1081%** | -52.6% |

**结论**：0.80 彻底消除 1GB 高压（双机 ~16GB 余量，总 124.5GB 的 13%）；KV 池 2.56M 对 600k 上下文富余（max concurrency 4.27×）
