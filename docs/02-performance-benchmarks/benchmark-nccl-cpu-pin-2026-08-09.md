## 📌 TL;DR（执行摘要）

- 整体结论：**隔离核专用于 NCCL 可行且有效**——`taskset -c 18-19` 绑核消除调度抖动（短窗长尾 i_p99 128-459→79-189µs）；**核心收益来自 NCCL_PROTO=LL**（avg -32%，16B all_reduce 25.7→17.3µs）。
- **P99 ≤ 20µs 目标不可达成**：绑核+LL 最佳组合 i_p99 仍 **25-36µs**（差 5-15µs），偶发尖峰来自 IRQ/softirq 无法绑隔离核（ARM64 GIC 限制）。
- **🚨 关键架构发现：链式拓扑（04—02—01）下 3-rank NCCL all_reduce 无法 init**——01↔04 无直连且 GID 网络隔离（L1: 10.100.x vs L2: 10.20.0.x），RING/Tree/PXN 均需对角边 → `ibv_modify_qp timeout(110)`。**"NCCL RING 消化对角"在链式拓扑不成立，需成环（补 03 或 01↔04 直连）**。
- 严重度分布：🟡 2 项（P99 目标差距、链式拓扑 3-rank 不可行）/ 🟢 绑核与 LL 优化已验证。
- 阻塞 / 非阻塞：**非阻塞**（2-rank 通信可用；对角需拓扑决策）。

## 📊 二、核心结论

### 2.1 绑核：可行，抖动改善显著，稳态趋同
- ✅ 进程亲和不受 isolcpus 限制（ARM64 限制仅在 IRQ 亲和）
- ✅ 短窗口长尾抖动：i_p99 128-459 → 79-189µs（cv 减半）；稳态（-n5000）绑核与基线 avg 相当（25.6 vs 23.7µs），IP p99 略优（27.7-37.9 vs 31.7µs）
- 单核（②b）与双核（②）无差异（2-rank 实际只用 1 核）

### 2.2 NCCL_PROTO=LL 是核心收益（非绑核）
- avg 25.7 → **17.3µs（-32%）**，i_min 13.3µs，i_p99 25-36µs
- 结论：**绑核 + LL = 当前最佳组合**（avg 17.3µs / i_p99 25-36µs）
- 多通道/QPS（④）对小消息无益（验证带宽向优化无用）

### 2.3 🚨 链式拓扑 3-rank NCCL 不可行（架构级发现）
- 链式 04—02—01 无闭合物理环：01↔04 无直连 + GID 网络隔离（L1 10.100.x vs L2 10.20.0.x 不同子网）
- RING/Tree/PXN 算法均需 01↔04 通信 → `ibv_modify_qp timeout(110)` → **NCCL all_reduce 无法 init**
- 之前"对角由 NCCL RING 中继"的设想在链式拓扑下**不成立**；对角组合估计（T2_12+T2_24 ≈ 51µs）仅模型推导，非实测
- **对应用户目标的影响**：01↔04 的 NCCL 通信（无论绑核与否）在链式拓扑物理不可行

### 2.4 P99 ≤ 20µs 判定（对齐 Tessa 理论 + Rex 实测）
| 依据 | 结论 |
|---|---|
| 物理下限 | 单步 wire 3.27µs + launch ~7µs + NCCL/驱动 ~6µs ≈ 16µs > 单步 10µs 需求（对角 2 步） |
| 实测最佳 | 绑核+LL i_p99 25-36µs（差目标 5-15µs） |
| 根因 | IRQ/softirq 无法绑隔离核（ARM GIC），偶发尖峰 i_max 仍可达 633µs |
