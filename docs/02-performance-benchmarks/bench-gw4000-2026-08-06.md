## 结论与建议

1. **4000 网关功能与性能达标**：27/27 矩阵 0 错误、GSM8K 94.5%（-0.5pp 无实质回退）、0 超时；LiteLLM 层对短 ctx 聚合吞吐约 -17~-24%（相对直连 8001），延迟同量级。
2. **probabilistic 收益经 4000 延续**：结构化负载 c5 512 接受率 82–85%（散文 41%），输出吞吐 +38~49%；生产调用方保持 temp>0.1 即可生效。
3. **长上下文是吞吐瓶颈**：8192/32768 档输出吞吐 5–26 t/s，TTFT 16–50s，属 prefill 主导；若业务多为长上下文，建议关注 prefill 优化而非 decode 吞吐。
4. **建议**：GSM8K 类确定性任务继续走 temp=0.6 以上路由（精度 94.5% 与直连同量级）；结构化/工具调用负载保留 prob key 全量收益。
