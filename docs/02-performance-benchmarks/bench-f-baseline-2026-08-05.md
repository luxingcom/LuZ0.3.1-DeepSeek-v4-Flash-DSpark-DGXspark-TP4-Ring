## 结论与建议

1. **新基线固化可行**：完整矩阵 12 组合 0 错误、无系统性回退；单流/并发吞吐与旧基线持平或略升；GSM8K -4.0pp 系 temp=0.6 口径差异（非回归）。
2. **probabilistic 收益确认延续**：结构化负载 c5 吞吐 122–132 t/s（散文的 1.55–1.61 倍），与 prob-eval 方向一致；生产调用方需保持 **temperature>0.1** 否则退化为 greedy。
3. **动态K + tilelang 无副作用**：大 ctx（32768）c5 80.8 t/s（旧 77.9，+3.8%）、接受率 52.6%，长上下文负载正常。
4. **建议**：GSM8K 类确定性任务如需 99% 精度可走 temp=0 路由（放弃 prob 收益）；结构化/工具调用负载保留 prob+temp=0.6 全量收益。
