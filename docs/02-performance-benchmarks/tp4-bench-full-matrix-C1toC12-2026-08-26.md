# 三、结论要点
1. **有效档位 C1~C8 全部完成、无崩溃**（C12 失真不作正式结论）。
2. DE 三任务在 C1→C8：prefill tps 单调下降（~1.4K→~350），decode tps 下降（~100→~30），TTFT 上升——并发分摊带宽符合预期。
3. PR 各档：短前缀（512/2048）TTFT <5s，长前缀（131K）TTFT 达 177s（长 prefill 单步延迟高）。
4. **131K 长前缀 + 高并发（C8/C12）是当前唯一软肋**（model_err/并发失真），Q1 待引擎侧根治（长 prefill 单步延迟 / worker 静默死亡链路）。
5. 网关现限 `MAX_CONCURRENCY=6`——若线上要跑 C8/C12 并发，需放宽网关限制（否则请求被限到 6 在飞，c12 永远测不准）。
