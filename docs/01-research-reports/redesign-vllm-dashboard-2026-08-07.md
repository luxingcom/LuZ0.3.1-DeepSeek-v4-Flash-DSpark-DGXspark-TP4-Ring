## 3. 风格统一规则（已实施）

| 维度 | 规则 |
|------|------|
| 标题 | 纯中文为主 + 英文缩写括号标注（如「首 token 延迟（TTFT）」） |
| 延迟单位 | 全站 **milliseconds**（TTFT/TPOT/ITL） |
| 吞吐单位 | tok/s / reqps；网络统一 **Bps**（expr 去掉 /1048576） |
| 百分比 | percent；平均接受长度 none + decimals=2 |
| 图例 | 统一 P50/P99/avg、running/waiting |
| 颜色 | P50=#5794F2（蓝）、P99=#F2495C（红）、avg=#FADE2A（黄）固定语义色防跨面板漂移 |
| 全局 | refresh=10s（原 2s 过激进）、timezone=Asia/Shanghai、默认 Last 30m |
