## 1. 死锁根因确认

**缺陷**：8/20 SEV1 复盘新增的 step 2.5 B12X 门禁（.bak-b12xgate-20260820 引入，自引入即带死锁）。门禁语义为：head TCPStore 就绪后、启 workers 前，轮询 head 日志出现 `Using 'B12X_MXFP4' Mxfp4 MoE backend` 才放行（限时 `${B12X_GATE_WAIT:-300}s`，超时中止+diagnose）。

**死锁闭环**（引用 g1-production-restore-2026-08-24.md §3.3）：
1. 编排 step 2.5 等 head 日志 `Using 'B12X_MXFP4'` 才启动 worker（意图：防多 worker 并行撞 b12x JIT 竞态）；
2. 但 head 的 vLLM 引擎核心初始化（parallel_state backend=nccl）需全部 4 rank 加入 NCCL 通讯域才推进到 MoE/B12X 加载；
3. head 单独启动阻塞在 NCCL peer 等待 → B12X_MXFP4 日志永不出现 → 300s `--distributed-timeout-seconds` 超时 → `RuntimeError: Engine core initialization failed. Failed core proc(s): {}`。

→ worker 被门禁挡住、B12X 又依赖 worker，互等死锁。昨晚已用直启路径（head-first + 5s 错峰 worker）成功绕过。

**正确修复目标**：门禁仍要保留"防多 worker 并行撞 b12x JIT 竞态"的意图，但放行信号必须是不依赖 4-rank 域的信号（TCPStore 即 head 容器启动即开），并用固定错峰替代"等 B12X 完成"。

### 2.2 核心 Diff（step 2.5 前后）

**修改前（buggy, v1.5-r11 + 8/20 门禁）**
```bash
# ---- 2.5 B12X 启动期隔离门禁 (防多 worker 并行撞 b12x JIT 竞态, 2026-08-20 SEV1 复盘新增) ----
log "[step 2.5/4] B12X 门禁: 等待 head 日志出现 'Using B12X_MXFP4' (最多 ${B12X_GATE_WAIT:-300}s)..."
B12X_READY=0
for ((i=0; i<${B12X_GATE_WAIT:-300}/5; i++)); do
  if grep -q "Using 'B12X_MXFP4' Mxfp4 MoE backend" "$HEAD_LOG"; then
    B12X_READY=1
    log "[ok] head B12X_MXFP4 后端加载成功 (第 $((i+1)) 次, $((i*5))s)"
    break
  fi
  if grep -qE "Engine core initialization failed" "$HEAD_LOG"; then
    log "[error] head 引擎核心初始化失败, 提前中止" >&2
    diagnose
    exit 1
  fi
  sleep 5
done
if [ "$B12X_READY" -ne 1 ]; then
  log "[error] head ${B12X_GATE_WAIT:-300}s 内未出现 B12X_MXFP4 日志, 中止" >&2
  diagnose
  exit 1
fi
```

**修改后（fixed, v1.5-r12）**
```bash
# ---- 2.5 B12X JIT 竞态错峰门禁 (修复版 2026-08-24, 替代 8/20 的 B12X 日志门禁) ----
# 原门禁死锁根因: head 引擎核心初始化 (parallel_state backend=nccl) 需全部 4 rank 加入
#   NCCL 通讯域才推进到 MoE/B12X 加载; 原门禁等 head 日志 "Using 'B12X_MXFP4'" 才启 workers,
#   head 单独启动阻塞在 NCCL peer 等待 → B12X_MXFP4 日志永不出现 → 300s 超时
#   "Engine core initialization failed" → 冷启动死锁 (见 g1-production-restore-2026-08-24 §3.3)。
# 修复: 门禁目标改为 TCPStore:25999 就绪 (head 容器启动即开, 与 step 2 同一信号) +
#   固定错峰 (B12X_JIT_STAGGER) 逐个启动 workers, 保留"防多 worker 并行撞 b12x JIT 竞态"
#   原始意图, 同时让 4 rank 尽快进入 NCCL rendezvous, 消除互等死锁。
log "[step 2.5/4] B12X 错峰门禁: 复核 TCPStore :${MASTER_PORT} 就绪 (最多 ${TCPSTORE_GATE_WAIT:-300}s), 随后按 ${B12X_JIT_STAGGER:-20}s 错峰启 workers"
TCPSTORE_READY=0
for ((i=0; i<${TCPSTORE_GATE_WAIT:-300}/5; i++)); do
  if ss -tln 2>/dev/null | grep -q ":$MASTER_PORT"; then
    TCPSTORE_READY=1
    log "[ok] TCPStore :${MASTER_PORT} 就绪 (第 $((i+1)) 次, $((i*5))s)"
    break
  fi
  if grep -qE "Engine core initialization failed" "$HEAD_LOG"; then
    log "[error] head 引擎核心初始化失败, 提前中止" >&2
    diagnose
    exit 1
  fi
  sleep 5
done
if [ "$TCPSTORE_READY" -ne 1 ]; then
  log "[error] TCPStore :${MASTER_PORT} ${TCPSTORE_GATE_WAIT:-300}s 内未就绪, 中止" >&2
  diagnose
  exit 1
fi
```

**step 3 错峰（修改后）**
```bash
for r in 1 2 3; do
  host="${RANK_HOST[$r]%%:*}"
  ip="${RANK_HOST[$r]##*:}"
  log "[step 3/4] 启动 rank${r} worker (${host}, ${ip}, HCA=${RANK_HCA[$r]})..."
  ssh -o BatchMode=yes -o ConnectTimeout=8 "$host" \
    "NODE_RANK=${r} VLLM_HOST_IP=${ip} NCCL_IB_HCA=${RANK_HCA[$r]} nohup bash $PROD/scripts/start_tp4_worker.sh > $HOME/start_tp4_rank${r}.log 2>&1 &"
  log "[i] rank${r} 启动命令已下发 (${host})"
  # B12X JIT 错峰: 除最后一个 worker 外, 间隔 ${B12X_JIT_STAGGER}s
  if [ "$r" -lt 3 ]; then
    log "[i] 错峰等待 ${B12X_JIT_STAGGER:-20}s (防多 worker 并行撞 b12x JIT 竞态)..."
    sleep "${B12X_JIT_STAGGER:-20}"
  fi
done
```
