## 0. 一页结论（三问直答）

| 三问 | 结论 | 证据强度 |

**一句话**：LuZ0.3.1 的 decode 中位回退 **不是 dspark 接受率下降、不是 C1 步时下降、主要是分布稳定性 + 接受率方差 + 既有官方环境差距** 三者的叠加；C12 并发 +1.9% 与高并发收益叙事自洽（W4A4 prefill 增益 + n7 接受率优势 + 并发平均效应盖过 C12 decode 步时 -8%）。

## 1. 归因框架（四因素模型）

decode 吞吐恒等式：

```
decode t/s = steps/s（真实推理速度） × tokens/step（dspark 接受率，= 1 + accepted/drafts）
```

四个因素沿此分解：

| # | 因素 | 作用面 | 关键观测点 | 与本次衰退的关联 |
|---|---|---|---|---|
| **F1 dspark 接受率** | tokens/step | 官方 n5→现 n7；同 n7 下 W4A16→W4A4 | tokens/step（de_bench 修正口径） | 官方 8/19 用 n5、现用 n7 —— **n7 接受率更高**；但官方原基座 draft 模型质量可能更高（既有差距） |
| **F2 真实推理速度（步时）** | ms/step | W4A4 decode 代价 + 形态收紧（thr4096/seqs12） | step_eff、ITL、步时 | W4A4 full decode 已知代价 -6~-9%（phase3b 口径）；C12 可测 -8.0%；C1 中性 |
| **F3 形态差异** | 并发聚合 | batched 8240→4096、seqs16→12、MTP n5→7、util 0.72→0.82、threshold | PR、C6/C12 聚合、TTFT | 解释 **C1 单流 -23.9% vs C12 +1.9% 的对比形态**：并发下批量效率 + n7 接受率 + W4A4 prefill 增益占优 |
| **F4 稳定性** | 中位 vs 最优 | 重启级模式方差、AR stall、接受率随机性、轮内干扰 | 10 轮分布形态、steps/s 是否恒定 | 最优值普遍提升 + 中位大幅回退 = **分布/尾部效应**，能力上限未退化 |

**决策树**：若接受率下降为主 → MTP 调参（n/采样）；若步时为主 → W4A4 decode 优化（lm_head FP8 等）；若不稳定为主 → 重测协议/交错 A/B。**本次证据指向：不稳定 + 接受率方差为主、C12 步时（W4A4 代价）为辅。**

## 2. 数据验证

### 2.1 接受率（tokens/step）—— 未下降，n7 反而高于 n5

**n 档扫描（同环境同文本，W4A16，mtp-tuning 08-22）【实测】**：

| 配置 | C1 acc_len | C12 acc_len | C1 步时 | C12 步时 | C1 tput | C12 tput |
|---|---|---|---|---|---|---|
| **n=7 prob（现）** | **4.34** | **4.22** | 49.5ms | 128ms | 87.5 | 395.4 |
| n=5 prob（官方档） | **3.66** (-16%) | **3.77** (-11%) | 45.7ms | 116.6ms | 80.1 | 387.9 |
| n=10 prob | 4.92 (+13%) | 3.74 (-11%) | 54.9ms | 151.5ms | 89.8 | 296.3 |

- **n7 vs n5：接受率 n7 显著更高（C1 +18.6%、C12 +11.9%），步时略慢（+8~9%）→ 净 tput 更高（C1 +8.5%、C12 +1.9% 噪声内）。** 官方 8/19 用 n5、现用 n7，仅就 n 档而言，本次形态**提升了**接受率，不是下降。且 mtp-tuning 已闭环 n=5/n=7/n=10/自适应四向扫描，n=7 是本负载近似最优。【实测】
- **W4A4 vs W4A16（同 n7，同日 A/B，w4a4-ext 08-23）【实测】**：DE step_eff B1(W4A16) 17.7/87.2 → B2(W4A4) 18.3/85.1，C1 +3.4% / C12 -2.4%（±3% 噪声带内，decode 中性）。**W4A4 量化 target 不改变 draft 提议/验证语义 → 无接受率变化机制**【推断】。
- **生产落地复核（luz031-deployment 08-23）【实测】**：DE C1 step_eff 18.2（vs B1 17.7，+2.8%）；C12 80.2（vs B1 87.2，-8.0%）。C1 接受率中性、C12 接受率中性（step_eff 已归一接受率）。
- **官方 8/19 的接受率**：官方参考用 n5、seqs16、batched 8240。08-21 e2e 报告明确记录"参考部署（n=5）C1 更高（97-124）的原因不在 n——其优势来自其他因素（draft 权重/构建差异），本集群不可据此调参"【实测旁证】。即 **官方 C1 领先中至少有一部分是官方原基座 draft 模型质量（每位置接受率更高）带来的既有差距**，与 LuZ0.3.1 变更无关。

**小节**：dspark 接受率**未**因 LuZ0.3.1 下降；n7→n7 同 draft 模型下接受率基本不变；vs 官方的接受率差距为既有 draft 模型质量差。

### 2.2 真实推理速度（步时 ms/step）—— C1 中性，C12 进入 W4A4 代价带

**同日/近窗 step_eff 对照【实测】**：

| 对比 | C1 step_eff | C12 step_eff | 判读 |
|---|---|---|---|
| w4a4-ext B1(W4A16) → B2(W4A4) | 17.7 → 18.3 (+3.4%) | 87.2 → 85.1 (-2.4%) | 同窗 A/B：decode 中性 |
| B1(W4A16) → LuZ0.3.1（生产） | 17.7 → 18.2 (+2.8%) | 87.2 → 80.2 (**-8.0%**) | C12 落入 W4A4 full 已知代价带 |

- **C1 步时未退化**：step_eff（≈ steps/s）C1 中性偏正。**因此 C1 单流中位 -23.9% 不能归因于步时**【实测】。
- **C12 步时 -8.0%**：vs B1（W4A16）的 -8.0% 与 phase3b 口径 W4A4 full decode 代价（-6~-9%）吻合；w4a4-ext 同日 B2 口径仅 -2.4%（噪声带内），两口径并存（luz031-deployment 已如实记录）。**W4A4 decode 代价主要作用于 C12（M≈96，MoE 权重读占主导），对 C1（M=8，固定开销占比高）影响被掩盖**【推断，与 P0 拆账的 M 依赖一致】。
- **P0 拆账旁证（luz031-bench Session B）【实测】**：C1 decode 带宽墙三池合计 7.49ms/step（M=8），其中 **bf16 稠密池（attn/shared/lm_head）17-18% 步时**不受 W4A4 影响；W4A4 的代价/收益只作用于 MoE routed experts 段。
- **官方 env 步时**：官方 C1 中位 97.1 @ n5。若官方接受率 = 我们 n5 的 3.66，则官方 steps/s ≈ 26.5 vs 我们 W4A16 n5 的 21.9（mtp-tuning cfg3）——**即使同为 W4A16 n5，官方隐含步时也更快**（draft 权重/构建/缓存差异）。该差距 08-21 已在案（我们 W4A16 C1 92.8 vs 官方 97.1），**非 LuZ0.3.1 引入**【实测旁证/推断】。

### 2.3 形态差异 —— 解释 C1 单流 -23.9% vs C12 +1.9%

| 维度 | 官方 8/19 | LuZ0.3.1 | 对 decode 的影响方向 |
|---|---|---|---|
| MoE 量化 | W4A16 | **W4A4 full + 池补丁** | decode 代价带 -6~-9%（C12 可见）；prefill +6.6~15%（PR 实测） |
| max_num_batched_tokens | 8240 | 4096（thr4096） | 并发调度更细、更贴合 W4A4 甜点（w4a4-ext：W4A4 受益曲线在 4096 见顶） |
| max_num_seqs | 16 | 12 | C12 满载不受限；C1 单流无影响 |
| MTP | n5 | n7 | 接受率 +11.9~18.6%（mtp-tuning）；步时 +8~9% |
| util | 0.82 | 0.82 | 相同 |

**C1 单流为什么 -23.9% 而 C12 +1.9%**：
- **C1 单流**：tput = steps/s（中性）× acc_len（n7，draft 模型既有权重）。C1 无并发平均效应，**每一轮都暴露原始接受率方差** → 中位被低接受率轮次拉低（§2.4）。n5→n7 的接受率优势在官方 draft 模型质量更好的前提下不足以追平中位。
- **C12 并发**：聚合 = 每流中位 × 12，**跨流平均抹平接受率方差**；同时吃到三份顺风——① W4A4 prefill/并发增益（w4a4-ext C12 聚合 +13.0%）② n7 接受率优势（C12 +11.9%）③ 批量调度效率（4096 分块在并发下命中 W4A4 甜点区）——足以盖过 C12 decode 步时 -8% → 净 +1.9%【推断，自洽】。
- **C4 中位 -14.4% 介于两者之间**：并发平均效应随并发度单调增强（C1 < C4 < C8 < C12 的回退幅度 -23.9% > -14.4% > -4.1% > +1.9% 完全符合该机制）【实测，趋势一致性】。

### 2.4 稳定性 —— 中位 vs 最优分离的机制

**当前 S1 fox p512 10 轮原始分布（Session A 日志）【实测】**：
```
72.6 / 71.9 / 131.1 / 65.2 / 110.1 / 110.2 / 66.9 / 83.3 / 81.4 / 74.3
→ 中位 77.8 | 均值 86.7 | 最优 131.1  （强双峰：7 轮低带 65-85，3 轮高带 110-131）
```

**官方 8/19 C1 10 轮分布（官方回归日志）【实测】**：
```
88.0 / 99.6 / 83.9 / 79.5 / 83.0 / 104.9 / 101.4 / 100.4 / 94.5 / 124.0
→ 中位 97.1 | 均值 95.9 | 最优 124.0  （对称分布，σ 小，无低尾）
```

**机制拆解（三层，按贡献排序）**：

1. **接受率随机性（主要）【实测】**：slowround 阶段 2 关键发现——**de C1 轮间 tput 方差 36.6% 完全由 MTP 接受率解释，steps/s 恒定 19.6-20.1**（同 prompt 下 steps/s 变化才是基础设施问题）。当前 Session A 的 S1 低带轮（65-85 t/s）≈ acc_len 3.7-4.3、高带轮（110-131）≈ acc_len 5.5-6.7，steps/s 恒定 → **低带轮是接受率随机性抽到的低接受轮，不是速度退化**。probabilistic draft 采样使每轮 draft 提议不同 → 接受长度轮间大幅波动【推断，机制与 mtp-tuning 的 temp-0 下 probabilistic=greedy 语义一致】。
2. **重启级模式方差【实测】**(expd-r123)：7 次抽签首请求 TTFT 双簇（慢 4.25-4.43s ×4 / 中 3.07-3.48s ×3），稳态 PR 差 ~3.4%；**模式按重启落点固定，Session A 为单次重启单模式**——不直接解释轮内双峰，但解释跨 session 对比（08-21 92.8 vs 本次 77.8）的一部分。
3. **AR stall（环境级，单核约束）【实测】**(expverdict-verdict)：stall 率 6/10（60%），AR med 17.99-21.18ms vs CLEAN 0.586-0.600ms，**12/12 完美相关 = 每次 STALL run 至少一节点 worker 被压到单核（CPU 8/9，proxy 目标核）**。但——生产稳态未观测到灾难性 stall（expD R1-R7 panorama 全带内），stall 主要在 nccl-tests 形态出现（communicator 生命周期差异）【实测旁证】。**对 Session A bench 的影响是潜在风险而非已证主因**【推断】。

**"最优值普遍提升"的含义**：C1 best +10.1%、C8 best +15.0%、C12 best +11.0%、Agent 工具 best +18.5%、S1 best +5.7% —— **能力上限未退化，甚至更高**（高接受轮次下 n7 + W4A4 prefill 顺风兑现）。中位衰退 = 低接受轮次占比过高把中位拉下去（分布形状问题），不是系统性能下降。**若把中位换成"高接受率轮次的能力上限"，则本次形态不劣反优**。

**不稳定贡献的量化口径（C1 单流）**【推断】：
- 中位 77.8 vs 均值 86.7 = **-10% 纯偏度损失**（接受率随机性）；
- 最优 +5.7% vs 官方 → 上限未退化；
- 08-21 W4A16 同项中位 92.8（均值 90.3，偏度小）→ **本次低接受率轮次出现频次/深度均高于 08-21**，是跨 session 不稳定 + 接受率随机性共同作用。

## 3. 三问明确回答

### a) dspark 接受率是否下降（n7 vs n5 / W4A4 vs W4A16）？—— **否**

| 证据 | 内容 | 强度 |
|---|---|---|
| mtp-tuning n 扫描 | n7 acc_len C1 4.34/C12 4.22 **高于** n5 3.66/3.77（+18.6%/+11.9%）；n7 已是本负载最优 | 【实测】 |
| w4a4-ext B1 vs B2 | W4A4 同 n7 下 step_eff C1 +3.4%/C12 -2.4%，接受率中性 | 【实测】 |
| luz031-deployment DE | LuZ0.3.1 C1 step_eff 18.2 vs B1 17.7（+2.8%） | 【实测】 |
| e2e-baseline 08-21 | "参考部署 C1 更高原因不在 n（draft 权重/构建差异）" | 【实测旁证】 |

**结论**：**没有接受率下降**。n5→n7 反而提升接受率；W4A4 无接受率机制。vs 官方中位差距中属于接受率的部分是**官方原基座 draft 模型质量优势**（既有差距，08-21 已在案），与本次变更无关。

### b) 真实推理速度（步时）是否下降？—— **C1 否；C12 进入 W4A4 已知代价带（-8%）**

| 证据 | 内容 | 强度 |
|---|---|---|
| luz031-deployment DE | C1 step_eff 18.2 vs 17.7（+2.8%，步时中性）；C12 80.2 vs 87.2（-8.0%） | 【实测】 |
| w4a4-ext B1 vs B2 | C1 +3.4% / C12 -2.4%（同日 A/B 中性带） | 【实测】 |
| phase3b 历史 | W4A4 full decode 归一 -6~-9% | 【实测旁证】 |
| P0 拆账 | C1 带宽墙 7.49ms/step，bf16 稠密池占 17-18% 不受 W4A4 影响 | 【实测】 |

**结论**：**步时没有系统性下降**。唯一可测回退是 C12 decode -8.0%，落在 W4A4 full 已知代价带内（采纳 LuZ0.3.1 时已知并接受）；C1 步时中性，**不足以解释 C1 -23.9%**。官方对比中的步时/环境隐含差距（draft 权重/构建/cache）为既有项。

### c) 不稳定因素占比？—— **C1 中位-最优分离的主因；对中位回退贡献最大**

| 证据 | 内容 | 强度 |
|---|---|---|
| Session A S1 10 轮 | 强双峰分布（7 低 65-85 / 3 高 110-131），中位 77.8 << 均值 86.7；官方对称分布 97.1≈95.9 | 【实测】 |
| slowround de C1 | 36.6% tput 方差 = 接受率随机性，steps/s 恒定 | 【实测】 |
| expd-r123 | 重启级模式方差 ±8-13%（PR 口径），warmup TTFT 双簇差 ~40% | 【实测】 |
| expverdict | AR stall 6/10，单核约束 12/12 完美相关；生产稳态未见灾难 stall | 【实测】 |
| 最优值普遍提升 | C1 +10.1%、C8 +15%、C12 +11%、Agent tool +18.5% → 上限未退化 | 【实测】 |

**结论**：**不稳定是 C1 中位回退的主要解释**。C1 -23.9% 中，能力上限其实 +10%，**整个中位回退是分布/尾部效应**：接受率随机性 + 重启模式方差 + （潜在）AR stall。重测协议（更多轮数、交错 A/B、按 steps/s 判慢轮）应优先采纳。

## 4. 四因素归因表（C1 单流中位 -23.9% 的分解）

> 口径：相对官方 8/19（n5/W4A16/seqs16/batched8240）。负值 = 拉低中位，正值 = 抬高。

| 因素 | 估计贡献 | 依据 | 强度 | 是否本次引入 |
|---|---|---|---|---|
| **F4 不稳定（接受率随机性 + 模式方差 + 潜在 AR stall）** | **主因：-15~-20% 量级**（中位 77.8 vs 均值 86.7 = -10% 纯偏度；低接受轮次占比/深度高于 08-21） | §2.4 双峰分布 + slowround steps/s 恒定 | 【实测+推断】 | 部分（Session A 形态更双峰） |
| **F1 接受率（vs 官方 draft 模型质量差）** | **次要：-5~-10% 量级**（既有差距，08-21 已在案；非本次引入） | e2e-baseline + mtp-tuning | 【实测旁证/推断】 | **否（既有）** |

## 6. 后续建议（按证据强度排序）

**主路径：不稳定优先治理 + 重测协议（F4）**
1. **重测协议升级（最高优先，零窗口成本）**：① 单流轮数 10→30（当前 10 轮双峰下中位不稳定）；② 报告同时给"中位/均值/最优/低接受率轮占比"，不再单用中位；③ 慢轮判定看 steps/s 非 tput（slowround 口径）；④ 跨 session 对比用**交错 A/B**（同窗跑 W4A16/W4A4 各一轮），消除重启模式方差。
2. **AR stall 生产风险闭环**：E5（对当前生产跑 panorama 3 轮）确认生产未中招；E3 定位单核约束触发机制（cpuset 瞬时收窄 vs 调度挤占），如确认 cgroup 层原因可低成本规避。

**次路径：W4A4 decode 优化（F2，C12 -8% 已知代价）**
3. **lm_head FP8 立项**（fi017 P1 第二）：唯一同时打 decode 带宽墙节点，C12 步时 -5~6% 预估，可抵消 W4A4 decode 代价。前提：校准 + KL 门 + 贪心逐字。
4. **FI 0.6.17 评估（fi017 已 Go 有条件）**：其 #4285/#4255 直接作用于 W4A4 decode 小 batch 路径与精度修复，是拉回 C12 -8% 的头号候选。

**不推荐（证据否定）**：
5. **MTP 调参（n 值/采样）**：mtp-tuning 已闭环 n5/n7/n10/自适应四向全负或噪声级，**n7 已近最优**；除非 thr2048 数据出现反证，否则不重开。
6. **threshold 回退 8192**：w4a4-ext 已证 8192 全线负增益 + KV 塌缩 -36.7%，方向关闭。
